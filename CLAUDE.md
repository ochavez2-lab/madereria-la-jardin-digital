## Objetivo del Sistema

> "Tengo un negocio de madera y un centro de rehabilitación. El sistema debe servir para:
> * Que un empleado principiante atienda como profesional usando la IA para consultar precios y stock.
> * Auditar conversaciones 24/7 para evitar robos o errores en los precios.
> * Vigilar el centro de rehabilitación y alertar sobre movimientos extraños de los pacientes."

## Especificaciones Técnicas

- **Servidor central:** Mac Mini
- **Cámaras:** PoE 4K con API abierta (Reolink / Hikvision)
- **IA:** Claude Code conectado vía terminal
- **Audio:** Transcripciones vía Whisper para detectar discrepancias en ventas
- **Análisis:** Logs de movimiento + transcripciones de audio
