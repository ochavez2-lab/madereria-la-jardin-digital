# madereria-la-jardin-digital
"Infraestructura digital para Maderería La Jardín. Repositorio central de estrategias de marketing, activos visuales minimalistas y optimización de leads para las sucursales de Tijuana y Rosarito."
# Maderería La Jardín - Operaciones Digitales
**Ubicación:** Nogal 3516, Col. Ciudad Jardín, Tijuana.

## 🎯 Objetivos del Proyecto
* Centralización de activos de marketing digital.
* Optimización de campañas en Facebook Ads (Meta).
* Gestión de flujos de trabajo con IA (Claude, Gemini, SaleAds).

## 🛠️ Stack Tecnológico
* **Generación de Texto:** Claude (Prompts de venta y atención).
* **Generación Visual:** Gemini (Imágenes minimalistas de productos).
* **Montaje Publicitario:** SaleAds.ia.

## 📁 Estructura del Repositorio
* `/prompts`: Scripts y comandos optimizados para IA.
* `/assets`: Catálogo visual limpio y sin ruido.
* `/metrics`: Seguimiento de costo por lead y rendimiento de ads.
