# POS Madereria La Jardin

## Requisitos
- Node.js instalado (nodejs.org)

## Instalar (solo primera vez)
```
cd pos
npm install
```

## Correr
```
node server.js
```

## URLs
- Cajero: http://localhost:3000/cajero.html
- Cliente: http://TU_IP:3000/cliente.html

La IP aparece en la terminal al arrancar.
